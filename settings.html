1. Set up your AI connection

Chrome’s built-in Gemini Nano. No API key needed.

Use desktop Chrome 138+ on a supported device. Setup may require 22 GB free space and either more than 4 GB GPU memory or 16 GB RAM with 4 CPU cores. Managed browser policies can disable AI.

Use your OpenAI API account. API usage may incur charges.

Create an OpenAI API key

Choose a model your API account can use with Responses and Structured Outputs.

2. Choose your planning style

Automatic chooses 3–12 steps. Custom allows a maximum of 3–30. Short assignments can use fewer steps without padding. No time limits.

Adds a help button to each plan step and saved task. Worked explanations are generated only when requested.

3. Allow your Canvas site

Access lets Stepwise read instructions and download PDF links you select. You can upload a PDF or paste text without granting a site permanent access.

4. Try your first assignment

Open an assignment, read the page, preview any PDF text, add missing requirements, then click Break this into steps. Reopening an existing assignment offers its saved plan. Review updates before adding any new suggestions.

Your data and PDF limitations

PDF limits: 3 files per page, 12 MB and 80 pages each. Text only; no OCR, diagram interpretation or password unlocking. Combined AI input is limited to 60,000 characters and a warning appears when shortened.
